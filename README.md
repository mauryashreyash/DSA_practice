# LeetCode Java Solutions 🚀

This repository contains my solutions to LeetCode problems implemented in **Java**.
The goal is to write **clean, optimized, and easy-to-understand code** while improving
problem-solving and DSA fundamentals.

- Medium
- Hard

Each problem is stored in a separate file with:
